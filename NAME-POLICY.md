# Name Policy

The names **AI4RA Unified Data Model** and **AI4RA UDM** are reserved by Nathan Layman for conforming versions of the standard. The CC BY 4.0 and Apache-2.0 licenses cover the content of this repository and do not grant rights in these names.

## Conforming versions

A version is conforming when it is either:

- a release published in this repository, or
- an implementation or a data provider whose conformance declaration passes the published checker, `scripts/check_conformance.py`, for a published UDM version. The rules are in [Conformance](vignettes/udm-conformance.md).

Conforming versions may use the names with the claim the checker reports, for example "AI4RA UDM 2.3 core + modules: governance" or "AI4RA UDM 2.3 provider: Award, Proposal".

## Non-conforming versions

A version that does not pass the checker must not be called "AI4RA Unified Data Model" or "AI4RA UDM". It may state that it is "based on the AI4RA Unified Data Model", with the attribution the license requires.

## References to the standard

Referring to the standard by name, in comparisons, citations or crosswalk documentation, needs no permission.
